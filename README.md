## 📋 Project Description

**ContactHub** is a contact management web application that allows users to add, update, delete, search, and organize their contacts.

The project focuses on practicing CRUD Operations with JavaScript while using LocalStorage to keep contact data available after refreshing the page.

---

## ✨ Features

- ➕ **Add Contacts** - Add new contacts with personal information
- ✏️ **Update Contacts** - Edit existing contact information
- 🗑️ **Delete Contacts** - Remove contacts with delete confirmation
- 🔍 **Search Contacts** - Search by name, phone number, or email
- ⭐ **Favorites** - Add or remove contacts from favorites
- 📞 **Phone Calling** - Call contacts using `tel:` links
- 📧 **Email Contacts** - Send emails using `mailto:` links
- ✅ **Form Validation** - Validate contact information before saving
- 💾 **LocalStorage** - Keep contact data after page reload
- 🔔 **SweetAlert2** - Display alerts and delete confirmations
- 📱 **Responsive Design** - Works across different screen sizes
